

This paper makes several contributions to blink detection in fatigue driving research. First, we propose a three-stage pipeline that screens for candidate epochs likely to contain blink activity using multi-channel amplitude screening, derives a threshold for each channel from these candidate epochs, and applies each threshold to its corresponding channel across all epochs to extract channel-wise blink regions.
To our knowledge, this is among the first frameworks to integrate these three stages explicitly to address the challenges associated with epoch structured EEG recordings.
Second, we systematically compare the proposed pipeline against baseline methods, including BLINKER ~\citep{kleifges2017blinker} and MNE~\citep{GramfortEtAl2013a}.
Finally, to support reproducibility, we release the source code for the proposed pipeline, the baseline implementations, and the scripts used to run all experiments reported in this paper\footnote{\url{https://github.com/pyresearchs/double_thresholding_blink}}.
This allows every result to be regenerated and the pipeline to be applied to other epoch structured EEG datasets.
