The corresponding error profiles differed across conditions (Table~\ref{tab:error-structure}), particularly in the balance between false positives and false negatives. BLINKER-concat produced 627.9 false positives and 23.5 false negatives per session, giving an FP:FN ratio of 26.675 and an overwhelmingly false-positive-heavy error profile. MNE-annot produced 276.7 false positives and 451.5 false negatives per session, with an FP:FN ratio of 0.613, indicating that its errors were false-negative-heavy. Both proposed configurations were closer to parity. Proposed-Mean produced 191.3 false positives and 158.7 false negatives per session, corresponding to an FP:FN ratio of 1.206, whereas Proposed-Med produced 208.0 false positives and 127.7 false negatives per session, with an FP:FN ratio of 1.628. Thus, both proposed configurations remained moderately false-positive-heavy, but Proposed-Med traded additional false positives for fewer false negatives than Proposed-Mean.
