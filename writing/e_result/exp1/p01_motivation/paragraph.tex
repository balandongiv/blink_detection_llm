The EEG channel-subset analysis tested whether a reduced electrode set was sufficient for Proposed-Med, because blink artefacts project most strongly over frontal scalp sites and the amount of the full montage required for detection remained unknown~\cite{croft2000removal,chang2016detection}. In Proposed-Med, Stage A screened epochs using a union rule over the channels provided to the pipeline, so changing the channel set also changed which epochs reached Stage B. Restricting the available channels therefore changed the detector itself rather than merely changing the signals presented to a fixed detector. Each channel subset was consequently re-run through the complete pipeline rather than evaluated by hiding channels from a detector trained with a different channel set.
