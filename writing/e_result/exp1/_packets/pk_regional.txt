Shared design:
  epoch duration = 30 seconds
  Stage-B centre = median (Proposed-Med)
  aggregation = region-mean: each electrode's own macro F1 is averaged over sessions,
    then those per-electrode means are averaged across the electrodes the subset
    contains (the same aggregation used for the per-electrode regions in
    tab:region_performance / fig:region_performance)
  comparison baseline = the same region's electrodes scored inside the full-montage
    run, on the same sessions (NOT the full-montage headline oracle F1)
  test = two-tailed Wilcoxon signed-rank, paired by session, Bonferroni-corrected
    within each dataset
  effect size = matched-pairs rank-biserial correlation

SCOPE NOTE (not a number, but a fact the paragraph must state):
  Each subset re-runs Stage A, Stage B and Stage C on that subset alone, so each
  subset is a self-contained detector rather than the full-montage detector with
  channels hidden. The paired comparison is against the SAME region's electrodes
  scored inside the full-montage run (not against the full-montage headline oracle
  F1), so this analysis tests whether isolating a region as its own detector changed
  how well that region's own electrodes performed, not whether the subset matched
  overall full-montage performance. It is not a leave-one-region-out analysis and
  does not measure the necessity of a region to the complete system.
