EXPERIMENT 1 DESIGN FACTS (single-electrode operation)

Raja:
  sessions = 46
  electrodes in the full montage = 32
  single-electrode selections evaluated = 6 (Fp1, Fp2, AF3, AF4, F3, F4)

Cao2018:
  sessions = 58
  electrodes in the full montage = 32
  single-electrode selections evaluated = 4 (Fp1, Fp2, F3, F4)

Shared design:
  epoch duration = 30 seconds
  Stage-B centre = median (Proposed-Med)
  each single-electrode selection reruns Stage A, Stage B and Stage C using that one
    electrode alone, so it is a complete self-contained one-channel detector, not the
    full-montage detector with channels hidden
  a single-electrode selection offers no channel to choose between, so these values
    carry no best-channel-per-session oracle, unlike every other condition in the
    article; they are what a deployed single-electrode system would produce
  test = two-tailed Wilcoxon signed-rank, paired by session, Bonferroni-corrected
    within each dataset
  effect size = matched-pairs rank-biserial correlation

FINE PER-ELECTRODE COMPARISON: SINGLE ELECTRODE ALONE vs THE SAME ELECTRODE SCORED
INSIDE THE FULL-MONTAGE RUN (Table tab:exp1_solo_vs_montage)
Each electrode is scored twice on the same sessions: once as the sole input to the
complete pipeline (single electrode), and once as that electrode's row inside the
full 32-channel Proposed-Med run, where Stage A screens epochs using every electrode
(full montage). delta F1 = full montage minus single electrode, so a positive value
means the rest of the montage helped. p is Bonferroni-corrected within each dataset
(6 electrodes on Raja, 4 on Cao2018).

Raja (corrected over 6 electrodes):
  Fp2: alone F1 = 0.8337, full montage F1 = 0.8682, delta F1 = +0.0345, p = 1.000, r = -0.148
  Fp1: alone F1 = 0.8373, full montage F1 = 0.8632, delta F1 = +0.0259, p = 1.000, r = -0.012
  AF4: alone F1 = 0.7516, full montage F1 = 0.8032, delta F1 = +0.0516, p = 0.001, r = -0.655
  AF3: alone F1 = 0.6759, full montage F1 = 0.7376, delta F1 = +0.0617, p = 0.002, r = -0.625
  F3: alone F1 = 0.3985, full montage F1 = 0.4565, delta F1 = +0.0579, p = 0.008, r = -0.560
  F4: alone F1 = 0.3998, full montage F1 = 0.4523, delta F1 = +0.0526, p = <0.001, r = -0.668
  not significant after correction: Fp2, Fp1
  significant after correction: AF4, AF3, F3, F4

Cao2018 (corrected over 4 electrodes):
  Fp1: alone F1 = 0.7765, full montage F1 = 0.7968, delta F1 = +0.0203, p = 1.000, r = -0.094
  Fp2: alone F1 = 0.7559, full montage F1 = 0.7845, delta F1 = +0.0286, p = 0.991, r = -0.176
  F3: alone F1 = 0.4930, full montage F1 = 0.5951, delta F1 = +0.1021, p = <0.001, r = -0.672
  F4: alone F1 = 0.4903, full montage F1 = 0.5799, delta F1 = +0.0896, p = <0.001, r = -0.631
  not significant after correction: Fp1, Fp2
  significant after correction: F3, F4

For the electrodes where the gain was significant, it was concentrated in recall
rather than precision: e.g. Raja AF4 recall 0.7010 alone vs 0.7767 full montage
(precision 0.8765 alone vs 0.8691 full montage); Cao2018 F3 recall 0.4323 alone vs
0.5495 full montage (precision 0.7132 alone vs 0.7264 full montage).


COARSE COMPARISON: SINGLE-ELECTRODE-ALONE REGION MEAN vs THE SAME ELECTRODES SCORED
INSIDE THE FULL-MONTAGE RUN, COLLAPSED TO THE COARSE FRONTAL REGION
(This is the single-electrode analogue of the anatomical-subset coarse-region
comparison in tab:exp1_subset_summary/tab:region_performance: instead of a
self-contained multi-electrode subset rerun, each electrode here is run completely
alone, one channel at a time. Every single-electrode selection in both corpora
belongs to the frontal region, so this collapses to one frontal-region comparison
per corpus, not four regions. F1 solo = mean, across the single-electrode selections'
own runs, of the session-level mean F1 across those electrodes; F1 montage = the same
electrodes' region-mean F1 scored inside the full-montage run, i.e. the SAME number as
the "Frontal" row of tab:region_performance / the F1-montage column of the "Frontal"
row of tab:exp1_subset_summary. One Wilcoxon signed-rank test per corpus, paired by
session; since this is a single comparison per corpus, no Bonferroni factor applies.)

Raja: electrodes = Fp1, Fp2, AF3, AF4, F3, F4 (n=6)
  F1 solo (single-electrode-alone region mean) = 0.6495
  F1 montage (same electrodes, region-mean, full-montage run) = 0.6968
  delta F1 = -0.0474 (i.e. -4.74 percentage points); p = <0.001; r = -0.798; n sessions = 46

Cao2018: electrodes = Fp1, Fp2, F3, F4 (n=4)
  F1 solo (single-electrode-alone region mean) = 0.6289
  F1 montage (same electrodes, region-mean, full-montage run) = 0.6891
  delta F1 = -0.0602 (i.e. -6.02 percentage points); p = <0.001; r = -0.716; n sessions = 58

For comparison only (already reported elsewhere, do not restate as new): the same
frontal electrodes, run instead as ONE self-contained 6-electrode (Raja) / 4-electrode
(Cao2018) subset rather than one electrode at a time, reached F1 subset = 0.6692
(Raja) / 0.6661 (Cao2018) (the "Frontal" row of tab:exp1_subset_summary) — higher than
running each electrode fully alone, but still below the same electrodes' full-montage
F1 of 0.6968 / 0.6891.
